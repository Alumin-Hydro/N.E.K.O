如何创建 Discord Bot？（四步）
  1. 打开 Discord Developer Portal，点 New Application 创建一个应用。
  2. 左侧 Bot 页 → Reset Token → 复制 Token 粘贴到上方。
  3. 关键：同一 Bot 页面往下找到 Privileged Gateway Intents，打开 Message Content Intent，否则猫娘收不到消息内容。
  4. 左侧 OAuth2 → URL Generator → 勾 bot → Bot Permissions 勾 Send Messages / Read Message History / Embed Links / Attach Files → 打开底部生成的链接，把 Bot 邀请进你的服务器。
Discord 设置 → 高级 → 打开「开发者模式」→ 右键用户头像 → 复制用户 ID。管理员会被猫娘当作主人。

如果 Discord 连不上，多半是需要代理。填你电脑上的 VPN/代理软件端口，通常 7890（Clash 系）或 1080（v2ray）。

展开查看常见 VPN 设置教程

常见软件端口速查：

FlClash / Clash Verge / Clash Meta 7890
Clash for Windows 7890
v2rayN / v2rayNG 10809
Shadowsocks 1080
其他软件 看设置里的「本地端口」或「SOCKS5/HTTP 端口」

关键：打开「允许局域网连接」

N.E.K.O 可能运行在其他设备（如手机、另一台电脑），需要 VPN 软件开启「允许局域网连接」或「Allow LAN」，否则代理只对浏览器生效。

格式：http://IP地址:端口，本机填 http://127.0.0.1:7890，其他设备填 http://电脑IP:7890
