如何创建 Discord Bot？（四步）
  1. 打开 Discord Developer Portal，点 New Application 创建一个应用。
  2. 左侧 Bot 页 → Reset Token → 复制 Token 粘贴到上方。
  3. 关键：同一 Bot 页面往下找到 Privileged Gateway Intents，打开 Message Content Intent，否则猫娘收不到消息内容。
  4. 左侧 OAuth2 → URL Generator → 勾 bot → Bot Permissions 勾 Send Messages / Read Message History / Embed Links / Attach Files → 打开底部生成的链接，把 Bot 邀请进你的服务器。
Discord 设置 → 高级 → 打开「开发者模式」→ 右键用户头像 → 复制用户 ID。管理员会被猫娘当作主人。
