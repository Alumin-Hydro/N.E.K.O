角色卡自适应

选择已有角色卡后，插件会创建一个明确标记的受控副本。原角色卡始终保持不变，只有你确认的沟通建议会写入副本。

Package-only 兼容：仅安装 .neko-plugin 即可，无需为旧宿主应用 core 补丁。managed-overlay route 只是可选快路；route 缺失或返回普通 404 时，插件会使用内置的条件校验 fallback。

    高级设置

    清理未绑定的受控副本

    这些角色卡带有本插件来源标记，但无法与当前绑定唯一对应。请选择明确名称后手动删除；当前正在使用的角色不会被删除。

    手动删除自适应副本

    副本默认保留，方便再次启用。删除前会先安全恢复；只有来源标记匹配时才会删除。
