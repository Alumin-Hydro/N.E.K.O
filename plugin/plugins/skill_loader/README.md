# Agent Skills 技能库

`skill_loader` 把一个 Agent Skill 安全复制到 N.E.K.O 的托管目录，让猫娘按需读取它的说明与关联资料。脚本能力默认关闭；只有用户在管理面板中逐技能检查并显式授权后，猫娘或面板试用才可以请求运行。

## 支持矩阵

| 内容 | 导入与展示 | 按需读取 | 执行 |
| --- | --- | --- | --- |
| `SKILL.md` | 支持，解析 frontmatter 并保存 manifest | 支持，严格 UTF-8 | 不适用 |
| `references/` | 支持，保留相对目录 | 支持文本文件 | 不执行 |
| `templates/` | 支持，保留相对目录 | 支持文本文件；二进制仅列元数据 | 不执行 |
| `assets/` | 支持，保留相对目录 | 支持文本文件；二进制仅列元数据 | 不执行 |
| `scripts/*.py` | 支持，记录哈希、解释器与依赖诊断 | 支持读取文本 | 仅在逐技能授权后支持 |
| 其他脚本或可执行文件 | 可作为普通关联文件导入（仍受安全检查） | 仅在可安全解码时读取 | 不支持 |

目录导入会创建完整的 managed copy；后续读取和运行只使用这份托管副本，不会在运行时回读任意来源目录。粘贴模式只创建一个 `SKILL.md`，适合没有关联文件的轻量技能。

## 使用

1. 在面板“导入根目录与安全上限”中配置允许的来源根目录并保存。
2. 导入包含 `SKILL.md` 的技能目录，检查来源、manifest、linked files、脚本和依赖诊断。
3. 猫娘可通过工具列出技能，并按需读取 `SKILL.md` 或 manifest 中的指定关联文件。
4. 如确实需要脚本，先检查脚本内容和依赖，再对该技能单独授权。授权本身不会运行脚本；撤销会立即恢复硬拒绝。
5. 在面板中选择脚本、每行填写一个 argv 参数并试用，或在明确请求时让猫娘调用脚本工具。运行结果会显示状态、有限的 stdout/stderr 摘要与托管输出工件路径。

## 安全边界

- 导入仅接受允许根目录内的普通目录和普通文件；拒绝路径穿越、逃逸符号链接、特殊文件、硬链接异常及越界读取。
- 每个技能最多导入 256 个文件和 256 个目录，目录深度最多 16 层；单文件最多 8 MiB、全部文件合计最多 32 MiB，`SKILL.md` 最多 1 MiB，frontmatter 最多 64 KiB，相对路径最多 512 UTF-8 bytes。可读文本、依赖扫描、脚本输出和工件另有更窄的运行时上限，面板会显示实际值。超过限制会拒绝导入或明确截断输出，不会静默跳过安全检查。
- 脚本默认禁用并按技能授权。技能刷新后只要 manifest/脚本内容变化，旧授权即失效。
- 目前唯一受支持的执行格式是导入到 `scripts/` 下的普通 `.py` 文件，且必须找到可用的受支持 Python 解释器。参数按 argv 数组传入，始终 `shell=False`，不会附加 yolo、skip-permission 或类似绕过参数。
- 运行工作目录固定为技能 managed root；写入只允许落在该次运行的托管输出目录。运行受超时、进程树清理、最小环境、stdout/stderr 与工件大小限制约束。
- 每次运行会通过 `NEKO_SKILL_OUTPUT_DIR` 告知脚本唯一的托管输出目录；希望返回工件的脚本需要把文件写到该目录（或其子目录），写到技能说明、模板等只读位置会被拒绝。
- 缺少解释器或 Python 模块时只返回可操作的诊断；插件不会自动安装依赖、不会修改系统 Python，也不会盲目执行包管理命令。
- 猫娘只能读取 manifest 中已经导入的相对路径，不能借此读取任意主机文件。二进制模板和素材只向 LLM 暴露元数据，不会把原始主机文件直接塞进上下文。

Python runner 使用独立解释器、路径复核和 Python audit hook 做纵深防御，但它不是操作系统级容器。它不能承诺隔离恶意原生扩展，也不能等同于系统沙箱或网络隔离；因此只应授权你理解并信任的技能脚本。

导入时的依赖诊断来自 `requirements*.txt` 与 Python 静态 import 扫描，是保守的预检而不是完整包解析器；动态或可选 import 可能需要技能作者调整。当前也不会自动替换脚本里的输出路径，未使用 `NEKO_SKILL_OUTPUT_DIR` 的脚本可能需要适配后才能返回工件。

工件上限按单次运行执行；当前版本还没有跨历史运行的总磁盘配额或自动保留策略。长期频繁运行大工件技能时应自行清理不再需要的技能/运行数据。

## 兼容范围

插件实现 Agent Skills 常见的 `SKILL.md` + `references/`、`templates/`、`assets/`、`scripts/` 目录模型，并提供 N.E.K.O 原生的列出、读取和受控运行工具。它不会模拟 Claude Code、OpenClaw 或其他宿主的全部权限模型、专有工具、hook、子代理或安装器；依赖这些宿主特性的技能可能需要人工调整。
